## Strategi Pencarian (Indonesia-first)

1. Prioritas keyword lokal: komponen yang masuk "terlaris" Tokopedia/Shopee ID (SG90, HC-SR501, MQ-135, ESP32-C3 SuperMini, dll).
2. Sumber host terbuka yang sudah proven: `cdn.shopify.com`, `wp-content/uploads`, `m.media-amazon.com`, scccltd, thesciencehut, quartzcomponents, makerselectronics, vishaworld, einstronic, genzyug, uchidg, makershop.ie, etechnophiles, richelectronics, hubtronics `/image/cache/`, toolboxbd, camdenboss.
3. Host terblokir (skip): alicdn, imimg, mouser, diytech, wiki.wemos.cc, hiletgo.
4. Setiap batch: search → download → verifikasi PIL → update tabel status ✅ di file ini.
